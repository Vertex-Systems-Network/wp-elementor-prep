### Required implementation evidence

1. An SDK descriptor, `analyze → plan → generate → validateStatic` boundary consuming only the P17 IR, with profile and unsupported-feature coverage. Generated files must be deterministic from the same IR/profile/adapter version.
2. Adversarial fixtures for text escaping, unsafe URLs, asset traversal/missing bytes, duplicated IDs, REVIEW nodes, deep/oversized input and stale profile/source. Check no HTML injection or uncontrolled resource requests.
3. A pinned local React/TypeScript/Vite fixture with compiler/typecheck and production build. Record actual resolved versions and lockfile; do not use floating `latest` in generated package.
4. A controlled browser render at explicit viewport(s), verifying source-bound DOM identity, text, links, hierarchy, computed flex layout/gap, stylesheet closure and loaded local images. The retained receipt also records request closure and rejects inline handlers. A render pass is not a Figma visual-parity pass; measured comparison remains separate.
5. Exact artifact hashes and failure receipt. Keep statuses separate: static validation, build, preview render, image closure, source comparison and production acceptance.
